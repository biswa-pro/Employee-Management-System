# Employee Management System

A simple full-stack Employee Management System built using Java, Spring Boot, Spring Data JPA, PostgreSQL, HTML, CSS, and JavaScript.

The application allows authorized users to manage employee records through a simple and responsive web interfac


## Features

   Add Employee
-  View Employees
-  Edit Employee
-  Delete Employee
-  Search Employees
- 📱 Responsive User Interface
- 🗄️ PostgreSQL Database
- 🔄 RESTful APIs
